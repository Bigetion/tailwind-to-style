# twsx StackBlitz Starter Concept

This demo mirrors the Tailmantic StackBlitz starter idea, but in the preferred authoring style of `tailwind-to-style`:

- component-first object config
- minimal registry boilerplate
- concise `tw({ ... })` definitions
- no forced `register()` ceremony
- static CSS export path remains possible through the hybrid build flow

## Run it

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
